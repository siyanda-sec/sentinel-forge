# sentinel-forge

Cybersecurity lab focused on SOC monitoring, SIEM, detection, and incident response.

## About

Sentinel Forge is a hands-on cybersecurity lab designed to develop practical skills in security monitoring, threat detection, investigation, and incident response.

The project uses controlled lab environments to simulate security events and analyse the resulting evidence.

## Objectives

- Build and maintain a small cybersecurity lab
- Practice network reconnaissance and traffic analysis
- Collect and analyse security logs
- Configure and use a SIEM
- Develop and test security detections
- Investigate simulated security incidents
- Document findings and evidence
- Develop basic security automation

## Lab Environment

- Kali Linux
- Windows
- Ubuntu Server
- Wazuh
- Wireshark
- Nmap
- Python
- Bash / PowerShell
